# Currency Converter Application

A Java console application for bi-directional currency conversion between INR and foreign currencies, featuring dynamic rate management, currency removal, and input validation[cite: 1].

---

## 🚀 Features

* **Bi-Directional Conversion**: Convert INR to foreign currency and foreign currency to INR[cite: 1].
* **Currency Management**: Add new currencies, update conversion rates, and delete existing currencies[cite: 1].
* **Robust Input Validation**: Rejects invalid menu choices, non-numeric values, blank codes, duplicates, and non-positive rates/amounts[cite: 1].
* **Pre-loaded Data**: Includes initial exchange rates for USD, EUR, GBP, AED, and JPY relative to INR[cite: 1].
